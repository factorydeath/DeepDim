# DeepDim

Мощное приложение для Android с root, которое затемняет экран **ниже системного
минимума яркости**. Работает как набор независимых слоёв, которые складываются:

1. **Вуаль** — полноэкранный чёрный оверлей (`TYPE_APPLICATION_OVERLAY`).
2. **Accessibility-оверлей** — `TYPE_ACCESSIBILITY_OVERLAY`, перекрывает системные
   панели и не скрывается приложениями, вызывающими `hideOverlayWindows()`.
3. **Системный Extra Dim** — `reduce_bright_colors_activated` и
   `reduce_bright_colors_level` через root.
4. **Аппаратная яркость** — `DisplayManager.setBrightness(...)` (API 37),
   `Settings.System` или прямая запись в `/sys/class/backlight` через root.
5. **Тёплый фильтр** — убирает синюю часть спектра.

## Возможности

- Круговой регулятор глубины и отдельные слайдеры слоёв.
- Пресеты: Чтение, Ночь, Кино, Макс, Выкл — с иконками и тактильным откликом.
- Таймер сна: 15/30/60/90 минут, авто-выключение и обратный отсчёт в уведомлении.
- Ночное расписание с точным будильником и возвратом прежнего состояния утром.
- Плитка быстрых настроек и четыре варианта виджетов: пресеты, мини, панель
  и большой переключатель — с подсветкой активного состояния.
- Русский и английский интерфейс, выбор языка в системных настройках Android 13+.
- Плавающая кнопка сброса (тап — открыть, удержание — выключить).
- Режим «Чистые скриншоты»: затемнение не попадает в скриншоты — вместо
  вуали работают Extra Dim (с root) или системная яркость.
- Правила для отдельных приложений через UsageStats с поиском по приложениям.
- Управление кнопками громкости (AccessibilityService).
- Плавное появление и исчезновение вуали, лёгкие анимации интерфейса.
- Проверка доступов: оверлей, уведомления, будильники, батарея, WRITE_SETTINGS,
  статистика и Accessibility — по одной кнопке.
- Автовосстановление после перезагрузки, журнал исходной яркости.
- Автоматическая выдача app-op разрешений через root.
- Диагностика: su, SELinux, appops, узлы подсветки, secure settings.
- Без сети, рекламы и телеметрии.

## Сборка

### Готовый APK

```bash
./tools/build_apk.sh
```

Скрипт использует `aapt2`, `javac`, `d8`, `zipalign` и `apksigner` из
`/opt/android-sdk` (build-tools 37.0.0, platform android-37.0), создаёт
`keystore/deepdim.jks` при первом запуске и подписывает
`DeepDim-1.2.2.apk` в корне проекта.

Требования: JDK 17+, Android SDK 37, `zip`.

### Android Studio

В проекте также есть Gradle-файлы. Откройте папку `DeepDim` в Android Studio и
соберите `assembleRelease`. Для release-подписи используйте keystore из
`keystore/deepdim.jks` (пароль `deepdim`, alias `deepdim`).

## Установка

```bash
adb install -r DeepDim-1.2.2.apk
```

При первом запуске приложение попросит root. После выдачи su оно автоматически
включит «Поверх других приложений», `WRITE_SETTINGS`, доступ к статистике
использования, точные будильники и уведомления.

## Управление

- **Круговой регулятор** — глубина вуали (0–95 %). Вращение сопровождается
  тактильным откликом (можно выключить в настройках).
- **Пресеты** — готовые настроения в один тап; активный пресет подсвечивается.
- **Таймер сна** — выключит затемнение через 15/30/60/90 минут.
- **Аппаратная яркость** — 0 % соответствует системному минимуму (на Pixel с
  Even Dimmer уходит ещё ниже).
- **Extra Dim** — системная цветовая матрица, работает поверх всего.
- **Расписание** — «Ночь» включается в окне и возвращает прежние параметры утром.
- **Доступы** — карточка в настройках показывает, что уже разрешено, и ведёт
  прямо в нужный системный экран.

## Безопасность

Если экран стал слишком тёмным, удерживайте плавающую кнопку у правого края или
выключите затемнение из уведомления. Все изменения яркости журналируются и
откатываются при выключении, перезагрузке и обновлении приложения.
